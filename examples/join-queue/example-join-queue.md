## How this is ranked

- Program value = customer-months: commission rate × commission window (lifetime counted as 24 months; flat bounties ÷ a $20/month reference plan; unpublished rates assumed 10%; terms not yet verified on the official page × 0.5).
- It compares programs against each other. It is not an earnings forecast: price, conversion rate, and traffic are not modeled.
- Network score = sum of program values ÷ one-time setup cost (Impact 3, Partnerize 3, PartnerStack 2; 1 if you already hold an account there; each direct/per-program portal 1).
- Within a network: highest value first, catalog priority breaks ties.
